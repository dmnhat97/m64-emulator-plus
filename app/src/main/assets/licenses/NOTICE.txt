Summary of modifications (GPLv3 section 5a)
-------------------------------------------

Changes relative to upstream Mupen64Plus AE (details in
docs/project_customization_and_merge_notes.md and the git history):

Improvements
  * Redesigned dark user interface: gallery, new Settings hub screen, preference
    screens with a toolbar shell, themed dialogs, import screen and splash.
  * Netplay: fixed a client crash that kept a device out of a session (the setup
    dialog was dismissed after being detached when a stale mDNS record caused a
    failed connection).
  * New gamer UI built with Jetpack Compose: home with a "Continue playing" hero card, library with
    search and favorites, game details panel, settings grid. It switches between a controller mode
    (focus rings, button hints, D-pad / A / B / X / Y / L1 / R1 navigation, landscape, full screen)
    and a clean touch mode (portrait or landscape) depending on how the player controls it.
  * Favorites and play-time statistics per game.
  * Added an "Open source licenses" screen (this notice, GPL text, link to source).
  * RetroAchievements support (softcore) from upstream Mupen64Plus AE, hardened:
    the exported host-override receiver was removed, login tokens are no longer
    written to the log, and the app identifies itself with its own user agent.
    It connects to retroachievements.org only when enabled and logged in.
  * Emulation core and graphics plugin fixes backported from the upstream
    projects (Mupen64Plus core, GPL v2 or later; GLideN64, GPL v2): bounds and
    validation checks (cart ROM, PIF, DMA, save states, textures, RDRAM access),
    RSP task handling, memory pak and Game Boy Transfer Pak fixes, a controller
    fix for Wipeout 64, new widescreen hacks and null/overflow checks in GLideN64.
  * Backported from upstream Mupen64Plus AE (GPLv3): support for ROMs larger than
    64 MB (core), fixes for resource leaks in file/zip/texture handling, a locale
    tag fix and removal of a duplicate legacy vibration call.
  * Profiles saved by older versions that selected the removed angrylion-plus
    plugin are switched automatically to the default plugin.

Removed
  * The angrylion-plus software renderer (its MAME license forbids commercial use).
  * The upstream FAQ, help-forum and credits menu entries and web links.

Other
  * Renamed to "XM64 Emulator Plus", new application ID, new launcher/splash assets.
  * Based on an earlier upstream snapshot. Not included: upstream's manual ROM-path
    entry (it requires the restricted "All files access" permission).

Individual source files keep their original copyright headers. Upstream files
that carry no per-file header are covered by the upstream project's license,
as stated above.
